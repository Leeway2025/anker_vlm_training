# 实验待办清单:1M 阶段增量方法(2026-08-11)

> 背景:700k 首跑双达标(RT 88.29 / SubKS 80.98),122MB 压缩档双过线。
> 本文档固化下一轮(round 2)可投的增量方法、预期收益与验收纪律。
> 总排序:**蒸馏(+0.3~0.7)> 收敛(+~0.5)> 121k 修正补入 > 域定向增强(+0.1~0.3)**。
> CoT/RL 不进队列(阶段 2 已排除,复活条件见 §3)。

---

## 1. 集成蒸馏:三层空间(合计预期 SubKS +0.3~0.7)

锚点:100k 档集成对单模实测 +0.67 SubKS / +0.55 RT(73.77→74.44 / 83.65→84.20);
蒸馏经验兑现率 = 集成增益的 60~90%。700k 档集成增益预计收窄至 +0.3~0.5。

**先花小钱定上限(第一动作)**:跑 700k 双模合议评测(一发推理 + logits
平均,几小时)。测出的集成增益就是蒸馏空间的硬上限——<+0.2 则砍预期别投大,
≥+0.5 则全链投入。dump 一次两处收租(蒸馏正课教材 + 压缩修补原料,
汤 u512 蒸馏链已跑通,增量成本只是 200 步扩成正课几千步)。

### 1.1 合议 logits 蒸馏回单模(最确定,估 SubKS +0.2~0.4)
60~90% 兑现率。与交付形态天然契合——客户要的是单模 adapter,集成没法交付,
**蒸馏是把集成分数变成可交付分数的唯一通道**。

### 1.2 噪声/规则平滑红利(本项目特有,估 +0.1~0.2,主要落 SubKS)
训练标签里混着"客户规则口径"和真实错标 ~1%(08-11 定性反转结论)。teacher
logits 是全量数据上学出的平滑规则边界,比逐条硬标签更一致;学生对着 logits
学 = 把规则边界"抄一遍干净的"。在规则偏离常识的边界类(m、k/l、A↔D)最有效。

### 1.3 teacher 扩标注(最大但最投机,估 +0.2~0.4)
1M 池里 ~300k 未进 700k 精选、121k 被剔除。teacher 给无标/嫌疑样本打软标签,
学生在"700k 硬标 + 300k 软标"上训——数据杠杆而非模型杠杆,蒸馏在 1M 上独有。
⚠️ **与 round 2"121k 修正补入"部分重叠,不得重复计功**;此项放最后,
等 1.1/1.2 兑现且 121k 补入结果出来后再决策。

## 2. 增强 v3 候选(五件,合计估 +0.1~0.3;大数据档增强边际天然缩水)

前置欠账:**v2(crop-zoom/对比度/遮挡)至今未过消融门**,先还账再上 v3。

### 2.1 域定向三件套(最对症,唯一可能超预期的)
通用增强教"通用不变性",我们的域偏移是具体的——SVD 里视觉 mlp 大改写就是在
补这些。直接模拟:
- **灰度/IR 模拟**(RGB→灰度 + 轻微色偏,p=0.3):强迫"白天彩色/夜间红外"
  学同一套语义,直接攻日夜域差;
- **低照度 + 传感器噪声**(gamma 压暗 + 高斯/泊松噪声):夜间样本的清晰版孪生;
- **鱼眼/透视畸变 warp**:模拟广角拉伸,对"边缘变形的人/车"学不变性。

特殊之处:这三件编码的不变性**连 1M 真数据都教不全**(同一事件不会同时有
彩色版和红外版)——数据量替代不了,是增强还有空间的唯一理由。
先验证靶子:混淆矩阵按"时段×类"切一刀,若夜间/IR 下稀有类是重灾区,
此项收益高于均值估计。

### 2.2 时序连续窗裁剪(便宜,补 v1 盲区)
frame dropout 是随机抽帧;连续窗(16 帧里训 12~14 连续帧,随机起点)模拟
"事件在片段不同相位出现"。只有预切 16 帧也能做,几行代码。

### 2.3 RandAugment / TrivialAugment 视频一致版
自动策略在幅度空间里搜,替代手工挑;约束 = 每个 op 全片同参数(v2 已有基建)。
价值在覆盖面,不在单点强度。

### 2.4 同类 CutMix / 背景置换(强,但工程重 + 有毒风险)
跨类 mixup 无路径(生成式文本标签没法插值)维持原判;但**同标签对之间**的
CutMix/背景换底不需要混标签:固定机位背景建模极容易(中值帧),把稀有类
事件贴到别的机位背景上,直接攻"稀有类 × 机位"组合稀疏。
⚠️ 拼接伪影可能教捷径("有接缝=q 类"),必须配伪影随机化,工程量上一个量级。
默认不做,除非 2.1~2.3 全部无效且稀有类×机位仍是主要失手桶。

### 2.5 vision token dropout(最便宜档)
训练时随机丢 5~10% 视觉 token,正则化 + 顺带模拟"关键帧缺失"。

### 红线(维持原判)
时序翻转(动作语义反转)、跨类 mixup(标签无法插值)——不做。

## 3. 已排除路线与复活条件(阶段 2 结论,1M 上不重开)

| 路线 | 排除依据 | 唯一复活条件 |
|---|---|---|
| CoT(常识链) | 感知瓶颈 + Gemini 常识口径在规则偏离区是反向教材 | 改**规则引用式 CoT**(卡标注质量不卡数据量,P1 仲裁子集试点级) |
| RL/偏好(KTO/GRPO) | 单 token 无探索空间;稠密监督优于稀疏偏好(定律) | 客户开始考核 description 质量(RLAIF 对口),当前场景不存在 |
| 辅助属性头 | 100k 实测零效应(+0.22 噪声带) | 无 |
| 纯加步数续训 | 收敛后续训 −1.44 过拟合 | 无 |

---

## 4. 验收纪律(全部沿用,不例外)

1. **每轮单变量、全表验收(RT/SubKS/KS 齐看)、不涨即回退**;
2. 增强类一律挂独立 flag **默认关**(v3 挂 `--augment-v3`),
   **干净 100k from-scratch 消融过门**才准进 1M 配方;
   不在 anneal/续训中途插增强(变量污染);
3. 蒸馏类先跑 §1 的上限测量,再决定投入深度;
4. 收益入账去重:teacher 扩标注(1.3)与 121k 补入不得重复计功;
5. 选模标尺不变:固定 val 卷,test 标签不进任何训练/选择/调参回路。
