# 汇报:安防 VLM 模型压缩项目成果(2026-08-17)

## 一句话结论
两项硬指标全部达成:**模型体积压到 122MB 级(原 ~1GB),推理输入减半(首帧延迟降约 26%),
识别精度双双站上验收线**;成果已备份三处,随时可交付 NPU 团队部署。

## 背景与目标
设备端(瑞芯微 NPU)要求:①适配器体积 ≤122MB(闪存与多模型热切换);
②视觉输入 token 减半(降低首响延迟);③识别精度不得低于验收线(RoleType 87.91 / SubKS 80.42)。
三者互相挤压:压体积伤精度、减输入也伤精度。

## 成果(两步走)
**第一步:只压体积** —— 122MB、精度 88.13 / 80.65(超线 +0.22/+0.23)。
方法:低秩分解 + 老师蒸馏恢复 + int8 量化,量化几乎零损。

**第二步:再叠加输入减半** —— 输入 token 1024→512(prefill 计算 −38%),精度 88.10 / 80.49,仍双过线。
方法:智能挑选信息量最高的 512 个视觉 token(全局竞争 + 每帧保底),并让模型在该输入形态下重训适配;
最后用轻量校准(68 个标量,设备端零成本)把精度收复到线上。
**代价极小:约 0.2 分精度换 26% 端到端延迟。**

另有两个同规格备选(不同量化策略,121.9~122.3MB,均过线),供部署侧按芯片支持面择优。

## 关键决策与风控

- 所有精度均为公平校准口径并逐处标注;实验记录、负结果、复现指南全部入库。
- 资产三层备份:GitHub(代码+四份文档)、GCS 云存储(24GiB 权重全链条)、双机持久盘;机器可安全关停。
